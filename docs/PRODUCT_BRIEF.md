# Savingor (SavingGo) — Product Brief

Savingor is a lightweight shopper-first mobile app that helps users discover local grocery and retail deals, scan receipts for savings, and manage smarter shopping lists — focusing on fast, useful features that save time and money.

- Target country: Canada-first (Ontario and major urban areas prioritized). 
- Primary user: Value-conscious shoppers who want quick access to nearby deals and simple tools to save money while shopping.

MVP (v0.1) features:
- Deals list (sorted and filterable) with search and basic sorting.
- Deal details page showing title, store, price and placeholders for validity and notes.
- Favorites (save deal) — placeholder in MVP UI for later wiring.
- Shopping List placeholder screen (create/manage later).
- Receipt Scanner placeholder screen (OCR planned later).

Planned v0.2+ modules (roadmap):
- Map view showing nearby deals (interactive pins).
- OCR receipt scanning and automated deal extraction.
- Price history and trend charts for popular items.
- Push notifications / price alerts and saved search alerts.
- User accounts, sync across devices, and sharing lists.

Monetization model:
- Free tier: basic search, filters, deals browsing.
- PRO subscription: advanced filters and alerts, OCR-powered receipt parsing, analytics and export features.

Notes:
- The repo is organized for rapid iteration: start with mock data and simple screens, then swap in repositories/APIs as backend matures.
- Keep UI minimal and useful; avoid large rearchitectures early on to ship quickly.
